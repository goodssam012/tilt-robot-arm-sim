# 🦾 기울기 로봇팔 시뮬레이터

스마트폰 1대의 **기울기 센서**로 가상 공간의 **3축 로봇팔**을 조종해 물건을 집어 옮기는 시뮬레이터입니다.

- **스마트폰**: 기울여서 로봇팔 조종 + 버튼으로 팔꿈치·집게·배경·시점 조작
- **PC 화면**: 3D 시뮬레이터 (Three.js) — 브러시드 알루미늄·건메탈·크롬 재질의 금속 로봇팔, 4손가락 집게, 밀기 충돌
- 미션을 완료하면 다음 단계로 자동 이동하고, **3단계부터 난이도가 올라갑니다**

## 실행 방법

### 방법 1. 웹에서 바로 (설치 없음, 추천)

1. PC에서 **https://goodssam012.github.io/tilt-robot-arm-sim/** 을 엽니다.
2. 화면의 QR 코드를 폰 카메라로 찍습니다. (QR을 못 찍으면 폰에서 같은 주소의 `phone.html` 을 열고 **방 코드** 5자리를 입력)
3. 폰에서 **시작하기**를 누르면 연결되고 게임이 시작됩니다.

- 설치, 명령어, 폰 보안 경고, 방화벽 설정이 모두 필요 없습니다.
- PC와 폰이 **인터넷**에 연결되어 있어야 합니다. 둘을 이어 주는 데 무료 공개 중계 서버(PeerJS)를 쓰고, 연결된 뒤에는 PC와 폰이 직접 통신합니다.
- 학교망 등에서 연결이 안 되면 같은 Wi‑Fi에 연결하거나 아래 방법 2를 쓰세요.

### 방법 2. `시작.bat` 더블클릭 (인터넷이 없거나 방법 1이 막힐 때)

준비물: [Node.js](https://nodejs.org) LTS, PC와 스마트폰 (둘 다 **같은 Wi‑Fi**)

1. 프로젝트 폴더의 **`시작.bat`** 을 더블클릭합니다. 처음 한 번은 필요한 프로그램을 자동으로 설치합니다(1~2분).
2. 브라우저가 자동으로 열리면 QR 코드를 폰으로 찍습니다.
3. 폰에서 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나오면 **[고급] → [계속(방문)]** 을 누릅니다.
   (이 방법은 PC가 직접 서버가 되어 자체 서명 인증서를 쓰기 때문입니다.)
4. 폰에서 **시작하기**를 누릅니다. 끝낼 때는 검은 창을 닫으면 됩니다.

> 폰이 접속되지 않으면 Windows 방화벽에서 Node.js의 "개인 네트워크" 접근을 허용해 주세요.
> 명령어로 실행하려면 `npm install` 후 `npm start` (브라우저 자동 열기: `npm run start:open`).

## 조작법

폰은 **화면이 위로 오도록 눕혀서 두 손으로** 잡습니다. 시작 순간의 자세가 기준(영점)이 되며, 언제든 **⊙ 영점** 버튼으로 다시 맞출 수 있습니다.

| 조작 | 동작 |
|---|---|
| 좌우로 기울이기 | 베이스 회전 |
| 앞뒤로 기울이기 | 어깨 (앞으로 숙이면 팔이 앞/아래로) |
| ▲ / ▼ 버튼 누르고 있기 (왼손 엄지) | 팔꿈치 올리기 / 내리기 |
| 집기 버튼 (오른손 엄지) | 한 번 누르면 집기, 다시 누르면 놓기 |
| ◀ 배경 / 배경 ▶ | 배경 전환 (5종) |
| 🎥 시점 | 카메라 시점 전환 (기본·위·옆·집게 따라가기) |
| 속도 / ↺ 다시 | 조종 속도 변경 / 미션 다시 하기 |

집게 아래의 **빨간 선과 점**이 물건이 떨어질 위치를 보여 줍니다.

### 키보드 (폰 없이 테스트)

`A/D` 베이스 · `W/S` 어깨 · `R/F` 팔꿈치 · `Space` 집게 닫기 · `G` 집게 잠금 · `Q/E` 배경 · `C` 시점 · `V` 녹화 · `P` 재생 · `L` 반복 · `Backspace` 다시 하기 · `N` 다음 단계 건너뛰기

## 충돌과 진동

- 로봇팔(위팔·아래팔·손목·손가락)이 물건에 옆에서 닿으면 **물건이 밀려납니다.** 밀린 물건이 다른 물건을 한 번 더 밀 수도 있고, 받침대 밖으로 밀리면 떨어집니다.
- 위에서 누르거나, 미션을 완료해 **고정된 물건·벽·바닥**에 부딪히면 팔이 그 방향으로 더 움직이지 않습니다.
- **바닥**은 팔·관절·손가락·들고 있는 물건의 두께까지 계산해 절대 뚫고 들어가지 않습니다. 바닥에 닿으면 폰이 두 번 끊어 진동하고, 화면 테두리가 주황색으로 번쩍이며 "바닥에 닿았어요"가 표시됩니다.
- 닿는 순간 폰이 **진동**하고 화면 테두리가 번쩍입니다. 물건에 닿으면 노란색·짧게, 벽·바닥처럼 단단한 곳에 부딪히면 빨간색·강하게, 계속 밀면 짧은 진동이 반복됩니다.
- 폰 화면 위쪽의 **진동** 표시를 누르면 진동을 시험할 수 있습니다. 옆의 숫자는 PC에서 받은 진동 신호 수입니다.
  - 숫자는 올라가는데 진동이 안 느껴지면: 무음·방해금지 모드를 끄고, **설정 → 소리 및 진동 → 진동 세기**(삼성은 "터치 피드백"·"미디어" 포함)를 올려 주세요.
  - 숫자가 안 올라가면: PC 시뮬레이터 화면을 새로고침해 주세요.
  - **아이폰**은 사파리가 웹 진동을 지원하지 않아서, iOS 18 이상에서만 약한 시스템 햅틱으로 대신합니다. 그보다 낮은 버전은 화면 번쩍임만 보입니다.
- 집게는 **손가락 4개**가 십자 레일을 따라 동시에 열리고 닫혀 물건을 사방에서 감쌉니다. 손가락은 각자 물건의 실제 표면(상자는 면·모서리, 원기둥·공은 곡면)에 닿는 순간 멈추고, 잡을 때 물건을 집게 가운데로 끌어오며 상자는 손가락과 면이 맞게 돌려 잡습니다.

## 녹화 · 재생 (티칭)

산업용 로봇처럼 **동작을 가르쳐 두고 똑같이 반복**시킬 수 있습니다.

| 버튼 (PC 화면 아래 / 폰) | 단축키 | 동작 |
|---|---|---|
| ● 녹화 | `V` | 미션을 처음 상태로 되돌리고 조종 동작 기록 시작 (다시 누르면 정지) |
| ▶ 재생 | `P` | 기록한 단계를 처음 상태로 되돌린 뒤 같은 동작을 자동 실행 |
| 배속 | | 0.5배 / 1배 / 2배 재생 |
| 🔁 반복 | `L` | 재생이 끝나면 처음부터 계속 반복 |
| 💾 파일로 저장 / 📂 불러오기 | | 기록을 `.json` 파일로 주고받기 |

- 폰 입력값이 아니라 **관절 각도와 집게 상태**를 기록하기 때문에, 재생하면 물건이 녹화 때와 같은 자리에 놓입니다.
- 녹화 중 미션을 성공하면 녹화가 자동으로 끝나고 저장됩니다. 마지막 기록은 브라우저에 남아 새로고침해도 유지됩니다.
- 재생 중에는 조종이 잠기고 제한 시간이 멈추며, 점수는 오르지 않습니다. 집게 끝이 지나간 길이 선으로 표시됩니다 (녹화: 빨강, 재생: 하늘색).

## 미션 단계

| 단계 | 내용 |
|---|---|
| 1 | 첫 번째 운반 — 상자 하나를 목표 구역으로 |
| 2 | 빙글 돌려서 옮기기 — 베이스 크게 회전 |
| 3 ⚠ | 색깔 분류 — **여기부터 제한 시간** |
| 4 | 장애물 넘기 — 벽 위로 들어 옮기기 |
| 5 | 높은 선반 — 높은 받침대 위에 놓기 |
| 6 | 탑 쌓기 — 상자 3개를 순서대로 쌓기 |
| 7 | 움직이는 컨베이어 — 움직이는 구역에 타이밍 맞춰 놓기 |
| 8~ | 자동 생성 — 물건 수↑, 구역 크기↓, 시간↓, 벽·높은 구역·움직이는 구역↑ |

시간 안에 못 끝내면 같은 단계를 다시 시작합니다. 점수는 물건 1개당 100점과 남은 시간 보너스로 계산합니다.

## 파일 구조

```
server.js            (방법 2) HTTP(3000)·HTTPS(3443) 서버 + WebSocket 중계, QR 생성
시작.bat             (방법 2) 더블클릭 실행: 설치 확인 → 서버 실행 → 브라우저 열기
.github/workflows/   (방법 1) main 에 올리면 GitHub Pages 로 자동 배포
public/net.js        연결 모듈: 로컬 Wi‑Fi(WebSocket) / 인터넷 직접 연결(PeerJS) 자동 선택
public/index.html    PC 시뮬레이터 화면
public/sim.js        금속 로봇팔 모델·충돌·집기·미션 진행·녹화/재생
public/missions.js   단계별 미션 정의 / 자동 생성
public/themes.js     배경 테마 5종
public/phone.html    스마트폰 조종기
public/controller.js 폰 연결·센서 권한
```
