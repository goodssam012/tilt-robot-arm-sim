# 🦾 기울기 로봇팔 시뮬레이터

스마트폰 1대의 **기울기 센서**로 가상 공간의 **3축 로봇팔**을 조종해 물건을 집어 옮기는 시뮬레이터입니다.

- **스마트폰**: 기울여서 로봇팔 조종 + 버튼으로 팔꿈치·집게·배경·시점 조작
- **PC 화면**: 3D 시뮬레이터 (Three.js) — 브러시드 알루미늄·건메탈·크롬 재질의 금속 로봇팔, 4손가락 집게, 밀기 충돌
- 미션을 완료하면 다음 단계로 자동 이동하고, **3단계부터 난이도가 올라갑니다**

## 실행 방법

준비물: [Node.js](https://nodejs.org) 18 이상, PC와 스마트폰 1대 (둘 다 **같은 Wi‑Fi**)

```bash
npm install
```

```bash
npm start
```

1. PC 브라우저에서 `http://localhost:3000` 을 엽니다.
2. 화면의 QR 코드를 폰으로 찍어 접속합니다.
3. 폰에서 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나오면 **[고급] → [계속(방문)]** 을 누릅니다.
   (폰의 기울기 센서는 HTTPS에서만 동작해서, 서버가 자체 서명 인증서를 만들어 씁니다.)
4. 폰에서 **시작하기**를 누르면 센서가 켜지고, 게임이 자동으로 시작됩니다.

> 폰이 접속되지 않으면 Windows 방화벽에서 Node.js의 "개인 네트워크" 접근을 허용해 주세요.

## 조작법

폰은 **화면이 위로 오도록 눕혀서 두 손으로** 잡습니다. 시작 순간의 자세가 기준(영점)이 되며, 언제든 **⊙ 영점** 버튼으로 다시 맞출 수 있습니다.

| 조작 | 동작 |
|---|---|
| 좌우로 기울이기 | 베이스 회전 |
| 앞뒤로 기울이기 | 어깨 (앞으로 숙이면 팔이 앞/아래로) |
| ▲ / ▼ 버튼 누르고 있기 (왼손 엄지) | 팔꿈치 올리기 / 내리기 |
| 집기 버튼 (오른손 엄지) | 한 번 누르면 집기, 다시 누르면 놓기 |
| ◀ 배경 / 배경 ▶ | 배경 전환 (5종) |
| 🎥 시점 | 카메라 시점 전환 (기본·위·옆·집게 따라가기) |
| 속도 / ↺ 다시 | 조종 속도 변경 / 미션 다시 하기 |

집게 아래의 **빨간 선과 점**이 물건이 떨어질 위치를 보여 줍니다.

### 키보드 (폰 없이 테스트)

`A/D` 베이스 · `W/S` 어깨 · `R/F` 팔꿈치 · `Space` 집게 닫기 · `G` 집게 잠금 · `Q/E` 배경 · `C` 시점 · `V` 녹화 · `P` 재생 · `L` 반복 · `Backspace` 다시 하기 · `N` 다음 단계 건너뛰기

## 충돌과 진동

- 로봇팔(위팔·아래팔·손목·손가락)이 물건에 옆에서 닿으면 **물건이 밀려납니다.** 밀린 물건이 다른 물건을 한 번 더 밀 수도 있고, 받침대 밖으로 밀리면 떨어집니다.
- 위에서 누르거나, 미션을 완료해 **고정된 물건·벽·바닥**에 부딪히면 팔이 그 방향으로 더 움직이지 않습니다.
- 닿는 순간 폰이 **진동**합니다. 물건에 닿으면 짧게, 벽·바닥처럼 단단한 곳에 부딪히면 강하게 울리고, 계속 밀면 짧은 진동이 반복됩니다.
  (진동은 안드로이드 폰에서 동작합니다. 아이폰 브라우저는 웹페이지 진동을 지원하지 않습니다.)
- 집게는 **손가락 4개**가 십자 레일을 따라 동시에 열리고 닫혀 물건을 사방에서 감쌉니다.

## 녹화 · 재생 (티칭)

산업용 로봇처럼 **동작을 가르쳐 두고 똑같이 반복**시킬 수 있습니다.

| 버튼 (PC 화면 아래 / 폰) | 단축키 | 동작 |
|---|---|---|
| ● 녹화 | `V` | 미션을 처음 상태로 되돌리고 조종 동작 기록 시작 (다시 누르면 정지) |
| ▶ 재생 | `P` | 기록한 단계를 처음 상태로 되돌린 뒤 같은 동작을 자동 실행 |
| 배속 | | 0.5배 / 1배 / 2배 재생 |
| 🔁 반복 | `L` | 재생이 끝나면 처음부터 계속 반복 |
| 💾 파일로 저장 / 📂 불러오기 | | 기록을 `.json` 파일로 주고받기 |

- 폰 입력값이 아니라 **관절 각도와 집게 상태**를 기록하기 때문에, 재생하면 물건이 녹화 때와 같은 자리에 놓입니다.
- 녹화 중 미션을 성공하면 녹화가 자동으로 끝나고 저장됩니다. 마지막 기록은 브라우저에 남아 새로고침해도 유지됩니다.
- 재생 중에는 조종이 잠기고 제한 시간이 멈추며, 점수는 오르지 않습니다. 집게 끝이 지나간 길이 선으로 표시됩니다 (녹화: 빨강, 재생: 하늘색).

## 미션 단계

| 단계 | 내용 |
|---|---|
| 1 | 첫 번째 운반 — 상자 하나를 목표 구역으로 |
| 2 | 빙글 돌려서 옮기기 — 베이스 크게 회전 |
| 3 ⚠ | 색깔 분류 — **여기부터 제한 시간** |
| 4 | 장애물 넘기 — 벽 위로 들어 옮기기 |
| 5 | 높은 선반 — 높은 받침대 위에 놓기 |
| 6 | 탑 쌓기 — 상자 3개를 순서대로 쌓기 |
| 7 | 움직이는 컨베이어 — 움직이는 구역에 타이밍 맞춰 놓기 |
| 8~ | 자동 생성 — 물건 수↑, 구역 크기↓, 시간↓, 벽·높은 구역·움직이는 구역↑ |

시간 안에 못 끝내면 같은 단계를 다시 시작합니다. 점수는 물건 1개당 100점과 남은 시간 보너스로 계산합니다.

