# 🦾 기울기 로봇팔 시뮬레이터

스마트폰 1대의 **기울기 센서**로 가상 공간의 **3축 로봇팔**을 조종해 물건을 집어 옮기는 시뮬레이터입니다.

- **스마트폰**: 기울여서 로봇팔 조종 + 버튼으로 팔꿈치·집게·배경·시점 조작
- **PC 화면**: 3D 시뮬레이터 (Three.js) — 브러시드 알루미늄·건메탈·크롬 재질의 금속 로봇팔, 4손가락 집게, 밀기 충돌
- 미션을 완료하면 다음 단계로 자동 이동하고, **3단계부터 난이도가 올라갑니다**

## 실행 방법

### 방법 1. 웹에서 바로 (설치 없음, 추천)

1. PC에서 **https://goodssam012.github.io/tilt-robot-arm-sim/** 을 엽니다.
2. 화면의 QR 코드를 폰 카메라로 찍습니다. (QR을 못 찍으면 폰에서 같은 주소의 `phone.html` 을 열고 **방 코드** 5자리를 입력)
3. 폰에서 **시작하기**를 누르면 연결되고 게임이 시작됩니다.

- 설치, 명령어, 폰 보안 경고, 방화벽 설정이 모두 필요 없습니다.
- PC와 폰이 **인터넷**에 연결되어 있어야 합니다. 먼저 PC와 폰을 **직접 연결**(WebRTC)하고, 폰이 LTE/5G이거나 학교·회사 Wi‑Fi처럼 직접 연결이 막힌 곳이면 **5초 뒤 자동으로 중계 서버**(공개 MQTT)를 거쳐 연결합니다. 이때 폰 위쪽에 **"PC·중계"**로 표시됩니다(조금 느림).
- 그래도 연결이 안 되면 폰 주소 끝에 `&via=relay` 를 붙여 처음부터 중계로 연결해 보거나, 아래 방법 2를 쓰세요.
- 폰 시작 화면에 연결 단계(PC 화면을 찾는 중… / 직접 연결됨 / 중계로 연결됨)가 표시됩니다.

### 방법 2. `시작.bat` 더블클릭 (인터넷이 없거나 방법 1이 막힐 때)

준비물: [Node.js](https://nodejs.org) LTS, PC와 스마트폰 (둘 다 **같은 Wi‑Fi**)

1. 프로젝트 폴더의 **`시작.bat`** 을 더블클릭합니다. 처음 한 번은 필요한 프로그램을 자동으로 설치합니다(1~2분).
2. 브라우저가 자동으로 열리면 QR 코드를 폰으로 찍습니다.
3. 폰에서 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나오면 **[고급] → [계속(방문)]** 을 누릅니다.
   (이 방법은 PC가 직접 서버가 되어 자체 서명 인증서를 쓰기 때문입니다.)
4. 폰에서 **시작하기**를 누릅니다. 끝낼 때는 검은 창을 닫으면 됩니다.

> 폰이 접속되지 않으면 Windows 방화벽에서 Node.js의 "개인 네트워크" 접근을 허용해 주세요.
> 명령어로 실행하려면 `npm install` 후 `npm start` (브라우저 자동 열기: `npm run start:open`).

## 조작법

폰은 **화면이 위로 오도록 눕혀서 두 손으로** 잡습니다. 시작 순간의 자세가 기준(영점)이 되며, 언제든 **⊙ 영점** 버튼으로 다시 맞출 수 있습니다.

| 좌우로 기울이기 | 베이스 회전 |
| 앞뒤로 기울이기 | 어깨 (앞으로 숙이면 팔이 앞/아래로) |
| ▲ / ▼ 버튼 누르고 있기 (왼손 엄지) | 팔꿈치 올리기 / 내리기 |
| 집기 버튼 (오른손 엄지) | 한 번 누르면 집기, 다시 누르면 놓기 |
| ◀ 배경 / 배경 ▶ | 배경 전환 (5종) |

| 속도 / ↺ 다시 | 조종 속도 변경 / 미션 다시 하기 |

집게 아래의 **빨간 선과 점**이 물건이 떨어질 위치를 보여 줍니다.

## 충돌과 진동

- 로봇팔(위팔·아래팔·손목·손가락)이 물건에 옆에서 닿으면 **물건이 밀려납니다.** 밀린 물건이 다른 물건을 한 번 더 밀 수도 있고, 받침대 밖으로 밀리면 떨어집니다.
- 위에서 누르거나, 미션을 완료해 **고정된 물건·벽·바닥**에 부딪히면 팔이 그 방향으로 더 움직이지 않습니다.
- **바닥**은 팔·관절·손가락·들고 있는 물건의 두께까지 계산해 절대 뚫고 들어가지 않습니다. 바닥에 닿으면 폰이 두 번 끊어 진동하고, 화면 테두리가 주황색으로 번쩍이며 "바닥에 닿았어요"가 표시됩니다.
- 닿는 순간 폰이 **진동**하고 화면 테두리가 번쩍입니다. 물건에 닿으면 노란색·짧게, 벽·바닥처럼 단단한 곳에 부딪히면 빨간색·강하게, 계속 밀면 짧은 진동이 반복됩니다.
- 폰 화면 위쪽의 **진동** 표시를 누르면 진동을 시험할 수 있습니다. 옆의 숫자는 PC에서 받은 진동 신호 수입니다.
  - 숫자는 올라가는데 진동이 안 느껴지면: 무음·방해금지 모드를 끄고, **설정 → 소리 및 진동 → 진동 세기**(삼성은 "터치 피드백"·"미디어" 포함)를 올려 주세요.
  - 숫자가 안 올라가면: PC 시뮬레이터 화면을 새로고침해 주세요.
  - **아이폰**은 사파리가 웹 진동을 지원하지 않아서, iOS 18 이상에서만 약한 시스템 햅틱으로 대신합니다. 그보다 낮은 버전은 화면 번쩍임만 보입니다.
- 집게는 **손가락 4개**가 십자 레일을 따라 동시에 열리고 닫혀 물건을 사방에서 감쌉니다. 손가락은 각자 물건의 실제 표면(상자는 면·모서리, 원기둥·공은 곡면)에 닿는 순간 멈추고, 잡을 때 물건을 집게 가운데로 끌어오며 상자는 손가락과 면이 맞게 돌려 잡습니다.

## 🖐 웹캠 손 조종 (스마트폰 없이)

PC 웹캠으로 **손가락과 팔을 인식**해서 로봇팔을 움직입니다. (MediaPipe 손·몸 인식, 브라우저 안에서 처리)

1. PC 화면 위쪽의 **🖐 카메라** 버튼을 누릅니다. 처음 한 번 인식 모델(약 14MB)을 받고, 카메라 권한을 물으면 **[허용]**.
2. 카메라 화면이 **크게** 열리면 **오른손(기본) / 왼손**을 고릅니다.
3. **보정:** 화면 안내를 따라 자세를 맞춥니다.
   - 몸이 안 보이면 앉을 자리가 **사람 모양 점선**으로 보입니다.
   - 어깨가 잡히면 고른 손 **어깨 앞에 목표 동그라미**가 나타납니다.
   - **손바닥을 카메라 쪽으로, 손가락은 위로 활짝**(하이파이브 하듯) 펴서 동그라미 안에 두세요. 팔꿈치는 살짝 굽힙니다.
   - 오른쪽 위 **체크리스트**(어깨·거리·손·손바닥 방향·손가락·동그라미)가 모두 ✓ 가 되면 동그라미가 초록색이 되고, 진행 고리가 다 차면 보정 끝.
   - 보정이 끝나면 카메라 화면이 원래 크기(오른쪽 아래)로 돌아갑니다.
4. 그다음부터 **집게가 내 손을 따라갑니다.**

**조종 방식 (카메라 창의 `방식` 버튼으로 팔꿈치 → 손 높이 → 위치 순서로 바꿈)**

**팔꿈치 방식 (기본)** — 오른손(고른 손) 하나로 조종합니다. 몸 인식으로 **위팔(어깨→팔꿈치) 각도**를 재서 로봇 어깨를 움직입니다. 내 몸통이 로봇 기둥, 내 위팔이 로봇 위팔이라고 생각하면 됩니다.

| 손·팔 동작 | 로봇팔 |
|---|---|
| 팔꿈치를 기준으로 손(아래팔)을 **오른쪽 / 왼쪽**으로 기울이기 | 베이스 회전 |
| 팔꿈치를 옆으로 **들기 / 내리기** (위팔을 수평 쪽으로) | **로봇 어깨**: 위팔 앞으로 눕히기 / 세우기 |
| 손목을 꺾어 **손바닥 숙이기 / 젖히기** | **로봇 팔꿈치**: 아래팔 내리기 / 올리기 |
| **주먹 쥐기** 또는 **엄지·검지 집기** / **손 펴기** | 집기 / 놓기 |

- 보정할 때 **팔꿈치를 몸 옆에 내리고** 굽혀서 손을 어깨 앞 동그라미에 둡니다. 이때가 로봇 위팔 세운 자세(85°)이고, 위팔이 수평이 되면 로봇 위팔도 수평(5°)이 됩니다.
- 회전은 팔꿈치를 기준으로 잰 손 위치로 계산해서, 팔꿈치를 들어도 회전이 바뀌지 않습니다. 아래팔을 약 50° 기울이면 끝(±170°)까지 돕니다.
- 미션 물건은 팔꿈치를 25~40° 들고 손바닥을 30~50° 숙이면 닿습니다.
- 카메라 창에 재고 있는 위팔이 **초록 선**, 수평 기준이 점선으로 보입니다. 팔꿈치가 화면에서 안 보이면 로봇 위팔은 그 자리에 멈춥니다.

**손 높이 방식** — 내 아래팔과 손이 로봇의 위팔과 아래팔을 그대로 따라 하는 방식입니다.

| 손·팔 동작 | 로봇팔 |
|---|---|
| 손을 **오른쪽 / 왼쪽**으로 | 베이스 회전 |
| 팔꿈치를 굽혀 손 **올리기 / 내리기** | **로봇 어깨**: 위팔 세우기 / 앞으로 눕히기 |
| 손목을 꺾어 **손바닥 숙이기 / 젖히기** | **로봇 팔꿈치**: 아래팔 내리기 / 올리기 |
| **주먹 쥐기** 또는 **엄지·검지 집기** | 집기 |
| **손 펴기** | 놓기 |

- 물건을 잡으려면 손을 조금 내리고(위팔이 앞으로 눕고) 손바닥을 숙이면(아래팔이 내려감) 됩니다. 미션 1~6단계 물건은 손을 상자 절반쯤 내리고 손바닥을 30~60° 숙이면 닿습니다.
- 아래팔은 **방향을 유지**합니다. 손목을 그대로 두고 손만 올리고 내리면 아래팔 방향은 그대로이고 위팔만 움직입니다.
- 손 기울기는 MediaPipe의 손 3D 좌표로 잽니다. 손을 숙여 손가락이 짧아 보여도 주먹·폄을 3D로 판단해서 잘못 집지 않습니다.
- 카메라 창 구석의 **작은 로봇팔 옆모습**에 지금 위팔(초록)·아래팔(파랑) 목표 자세가 보입니다.

**위치 방식 (이전 방식)** — 손 위아래 → 집게 높이, 손을 화면 쪽으로 밀기·당기기 → 집게 앞뒤 거리. 집게 위치에 맞게 어깨·팔꿈치 각도를 자동으로 계산합니다(역기구학).

두 방식 모두 충돌·집기·미션은 폰 조종과 똑같이 동작합니다.
- **손이 화면 밖으로 나갈 필요가 없습니다.** 보정 때의 손 위치(기준점 +)에서 화면 끝까지 남은 공간을 재 두고, 카메라 창의 **점선 상자** 안에서 로봇 회전 전체(±170°)와 위팔(손 높이 방식) 또는 높이(위치 방식) 전체가 나오게 맞춥니다. 가운데 근처는 천천히, 끝으로 갈수록 크게 돌아 정밀하게 조종할 수 있습니다.
- 카메라 창 아래쪽 **회전 게이지**와 옆쪽 **높이 게이지**로 지금 값을 볼 수 있고, 손이 점선 상자 밖(화면 끝)으로 가면 그쪽 테두리가 빨갛게 표시됩니다.
- 보정 때 **화면 가운데 쯤** 앉아야 양쪽 공간이 고르게 나옵니다. 몸이 기울어도 기준점은 그대로라 회전이 줄지 않습니다.
- 손이 안 보이면 로봇은 그 자리에서 멈춥니다.
- 진동 대신 **화면 테두리 번쩍임**과 소리로 닿음·충돌을 알려 줍니다.
- 반응이 너무 크거나 작으면 **감도**를, 자세를 바꿨으면 **⊙ 다시 보정**을 누르세요.
- 위치 방식의 앞뒤(밀기·당기기)는 손바닥이 커 보이는 정도로 추정해서 덜 정확합니다. 그래서 관절 각도를 바로 쓰는 팔꿈치 방식이 기본입니다. 밝은 곳에서, 뒤에 다른 사람이 지나가지 않게 하면 더 잘 됩니다.
- 카메라 조종이 켜져 있으면 1번 로봇팔(배틀의 1P)은 카메라로 움직입니다.

## 🎙 음성 명령 (내 목소리로 학습)

폰의 마이크로 **내 목소리를 직접 학습시켜** 집기·놓기(와 팔꿈치 올리기·내리기)를 말로 할 수 있습니다.

1. 폰 조종기에서 **🎙 음성** 버튼을 누릅니다. (처음 한 번 음성 인식 도구와 기본 모델 약 5MB를 받습니다)
2. 명령마다 **● 녹음**을 누르고 **2초 안에 아무 때나** 말합니다. 단어는 자유입니다 (예: "집어", "놓아"). 칸마다 **10번 이상** 권장. 잘못 녹음했으면 **↶ 마지막 녹음 지우기**.
3. **배경 소음**은 말하지 말고 3초씩 녹음합니다. 교실 소리·옆 사람 말소리가 섞여도 좋습니다.
4. **🧠 학습시키기** → 폰 안에서 20초~1분 학습하고, **처음 듣는 녹음으로 확인한 정확도**를 보여 줍니다.
5. **🎙 음성 조종 켜기** → 말하면 버튼을 누른 것처럼 동작합니다. 화면 위쪽 **🎙 표시**를 눌러 언제든 켜고 끌 수 있습니다.

**다시 학습할 필요 없음**
- 녹음과 학습 결과가 모두 폰에 저장됩니다. 다음에 열면 그대로 불러오고, 녹음을 더 해서 다시 학습할 수도 있습니다.
- 음성 조종을 켜 둔 채 끝냈다면, 다음에 **시작하기**를 누를 때 자동으로 다시 켜집니다.
- 학습 결과가 지워졌어도 저장된 녹음이 있으면 자동으로 다시 학습합니다.
- 저장은 **브라우저·주소별**입니다. 늘 같은 주소(웹 버전 추천)로 들어오세요. `시작.bat` 방식은 PC의 IP가 바뀌면 다른 주소로 취급됩니다.

**인식률을 높이는 방법 (적용된 것)**
- 단어를 2초 동안 녹음하고, 학습할 때 말한 부분을 중심으로 조금씩 밀린 여러 구간을 뽑아 배웁니다 → 말하는 타이밍에 덜 민감.
- 학습할 때 배경 소음을 단어에 섞어(노이즈 혼합) 시끄러운 곳에서도 알아듣게 하고, 기본 모델의 윗부분까지 내 목소리에 맞게 한 번 더 조정(미세 조정)합니다.
- 1초에 4번 듣고, 1등이 2등보다 확실히 앞설 때만 실행합니다. **확신도 기준**(기본 70%)은 화면에서 조절합니다.
- 녹음 팁: 실제로 쓸 때처럼 폰을 잡은 자세·거리·목소리 크기로, 조금씩 다르게(크게·작게·빠르게) 녹음하세요.

## ⚔ 2인 배틀 모드 (쟁탈전)

PC 화면의 **⚔ 2인 배틀 모드** 버튼(또는 `B` 키)으로 시작합니다. 폰 2대가 같은 QR로 접속하면 **먼저 들어온 폰이 1P(빨강), 다음 폰이 2P(파랑)** 가 되고, 폰 화면 위쪽에 자기 번호가 표시됩니다.

- 로봇팔 2대가 마주 보고, 가운데 물건을 집어 **내 구역(앞쪽 원)에 내려놓으면** 점수: 상자 1점 · 원기둥 2점 · 공 3점 · **황금 상자 5점**(20초마다 등장)
- 3·2·1 카운트다운 후 **90초** 동안 진행, 점수가 높은 쪽이 승리. 끝나면 ↺ 다시(폰) 또는 `Backspace` 로 재대결
- 두 팔은 서로 **부딪혀 막히고**, 상대가 노리는 물건을 **밀어내 방해**할 수 있습니다. 부딪히면 각자의 폰이 진동합니다.
- 가운데 물건이 줄면 위에서 새 물건이 떨어집니다.
- 폰이 한 대뿐이면 **2P는 PC 키보드**로 조종합니다(A/D·W/S·R/F·Space). 녹화·재생은 미션 모드에서만 쓸 수 있습니다.

## 녹화 · 재생 (티칭)

산업용 로봇처럼 **동작을 가르쳐 두고 똑같이 반복**시킬 수 있습니다.

| 버튼 (PC 화면 아래 / 폰) | 단축키 | 동작 |
|---|---|---|
| ● 녹화 | `V` | 미션을 처음 상태로 되돌리고 조종 동작 기록 시작 (다시 누르면 정지) |
| ▶ 재생 | `P` | 기록한 단계를 처음 상태로 되돌린 뒤 같은 동작을 자동 실행 |
| 배속 | | 0.5배 / 1배 / 2배 재생 |
| 🔁 반복 | `L` | 재생이 끝나면 처음부터 계속 반복 |
| 💾 파일로 저장 / 📂 불러오기 | | 기록을 `.json` 파일로 주고받기 |

- 폰 입력값이 아니라 **관절 각도와 집게 상태**를 기록하기 때문에, 재생하면 물건이 녹화 때와 같은 자리에 놓입니다.
- 녹화 중 미션을 성공하면 녹화가 자동으로 끝나고 저장됩니다. 마지막 기록은 브라우저에 남아 새로고침해도 유지됩니다.
- 재생 중에는 조종이 잠기고 제한 시간이 멈추며, 점수는 오르지 않습니다. 집게 끝이 지나간 길이 선으로 표시됩니다 (녹화: 빨강, 재생: 하늘색).

## 미션 단계

| 단계 | 내용 |
|---|---|
| 1 | 첫 번째 운반 — 상자 하나를 목표 구역으로 |
| 2 | 빙글 돌려서 옮기기 — 베이스 크게 회전 |
| 3 ⚠ | 색깔 분류 — **여기부터 제한 시간** |
| 4 | 장애물 넘기 — 벽 위로 들어 옮기기 |
| 5 | 높은 선반 — 높은 받침대 위에 놓기 |
| 6 | 탑 쌓기 — 상자 3개를 순서대로 쌓기 |
| 7 | 움직이는 컨베이어 — 움직이는 구역에 타이밍 맞춰 놓기 |
| 8~ | 자동 생성 — 물건 수↑, 구역 크기↓, 시간↓, 벽·높은 구역·움직이는 구역↑ |

시간 안에 못 끝내면 같은 단계를 다시 시작합니다. 점수는 물건 1개당 100점과 남은 시간 보너스로 계산합니다.
